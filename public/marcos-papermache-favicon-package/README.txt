PAQUETE DE FAVICONS

Archivos incluidos:
- favicon.ico: favicon multirresolución para navegadores.
- favicon-16x16.png / 32x32 / 48x48 / 64x64 / 96x96.
- apple-touch-icon.png: iPhone y iPad.
- android-chrome-192x192.png y 512x512.png: Android/PWA.
- mstile-150x150.png: mosaico de Windows.
- site.webmanifest: configuración PWA.
- browserconfig.xml: configuración para Windows.
- favicon-master-1024.png: versión maestra con esquinas transparentes.
- INSTALLATION.html.txt: etiquetas listas para copiar.

Para Next.js:
1. Copia todos los archivos dentro de /public.
2. Puedes conservar favicon.ico también en /src/app/favicon.ico si usas App Router.
3. Añade las etiquetas de INSTALLATION.html.txt en el <head> o configura metadata/icons.
